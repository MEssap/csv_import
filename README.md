# CSV 批量导入 Elasticsearch 工具

一个使用 Rust 开发的高性能 CSV 文件批量导入 Elasticsearch 工具，带有图形化界面。

## 功能特性

### 1. 文件读取
- ✅ 支持选择单个或多个 CSV 文件
- ✅ 支持选择文件夹，自动扫描所有 `.csv` 文件
- ✅ 使用原生文件对话框选择文件

### 2. CSV 解析与适配
- ✅ **自动检测分隔符**：智能分析前 10 行，自动识别 `,` `;` `\t` `|` 四种常见分隔符
- ✅ **手动指定分隔符**：也可在 GUI 中手动选择分隔符覆盖自动检测
- ✅ **编码自适应**：优先使用 UTF-8 解析，失败时自动 fallback 到 GBK/GB18030
- ✅ **BOM 支持**：自动处理带 BOM 的 UTF-8 文件
- ✅ **超长记录处理**：单条记录超过 100MB 时自动跳过并记录警告
- ✅ **异常行容错**：字段数不一致或包含非法字符的行会被跳过，不中断导入流程
- ✅ **灵活适配**：支持带/不带表头、不同编码、不同换行符（\r\n 和 \n）

### 3. Elasticsearch 导入
- ✅ 默认 ES 地址：`http://192.168.1.200:9200`（可在 GUI 中修改）
- ✅ 支持配置 ES 认证（用户名/密码可选）
- ✅ 使用 **Bulk API** 批量写入，性能优异
- ✅ Batch size 可配置（默认 1000 条/批次）
- ✅ CSV 第一行作为字段名，每行数据映射为一个 JSON 文档

### 4. 智能分块
- ✅ ES 单索引文档数上限：2,147,483,647（i32::MAX）
- ✅ 导入前通过采样估算总行数
- ✅ 超过上限时自动分块到多个索引：`{indexname}_01`, `{indexname}_02`, ...
- ✅ 未超过上限时使用原始索引名，不添加后缀
- ✅ GUI 显示预估总行数和分块数

### 5. 进度显示与错误重传
- ✅ **实时进度条**：显示已导入条数/总条数、百分比可视化
- ✅ **错误重传**：使用指数退避策略（1s → 2s → 4s），最多重试 3 次
- ✅ **详细日志**：实时显示导入日志，包括信息、警告、错误
- ✅ **统计信息**：导入完成后显示成功/失败/跳过条数和总耗时

### 6. 图形化界面
- ✅ 使用 **eframe/egui** 构建的现代化 GUI
- ✅ 界面布局清晰：配置区、文件选择区、操作区、进度区、日志区、统计区
- ✅ 后台线程执行导入，不阻塞 GUI 主线程
- ✅ 使用 crossbeam channel 进行线程间通信

## 项目结构

```
src/
├── main.rs          # 应用入口，启动 GUI
├── app.rs           # egui App 实现，GUI 布局和逻辑
├── csv_reader.rs    # CSV 读取、分隔符检测、编码处理
├── es_client.rs     # Elasticsearch Bulk API 客户端、错误重传
├── chunk.rs         # 行数估算、分块策略
├── import.rs        # 导入主流程编排
└── types.rs         # 共享类型定义、配置结构体、消息枚举
```

## 技术栈

- **GUI 框架**：eframe / egui
- **文件对话框**：rfd
- **CSV 解析**：csv
- **JSON 处理**：serde / serde_json
- **HTTP 客户端**：reqwest（blocking）
- **编码转换**：encoding_rs（GBK/GB18030）
- **异步运行时**：tokio
- **线程通信**：crossbeam

## 编译和运行

### 前置要求

- Rust 1.70 或更高版本
- 操作系统：Windows / Linux / macOS

### 编译

```bash
# 克隆仓库
git clone https://github.com/MEssap/csv_import.git
cd csv_import

# 编译（Debug 模式）
cargo build

# 编译（Release 模式，性能更优）
cargo build --release
```

### 运行

```bash
# Debug 模式
cargo run

# Release 模式
cargo run --release

# 或直接运行编译后的可执行文件
./target/release/csv_import  # Linux/macOS
.\target\release\csv_import.exe  # Windows
```

## 使用说明

### 基本流程

1. **配置 Elasticsearch 连接**
   - 输入 ES 地址（默认：`http://192.168.1.200:9200`）
   - 如需认证，填写用户名和密码
   - 输入目标索引名称（必填）
   - 设置批次大小（默认：1000）

2. **选择分隔符**
   - 默认使用"自动检测"
   - 也可手动选择：逗号、分号、制表符、竖线

3. **选择文件**
   - 点击"选择文件"按钮选择单个或多个 CSV 文件
   - 或点击"选择文件夹"按钮选择包含 CSV 文件的文件夹

4. **开始导入**
   - 点击"开始导入"按钮
   - 观察进度条和日志输出
   - 导入过程中可点击"停止"按钮中止

5. **查看结果**
   - 导入完成后查看统计信息
   - 检查日志中的警告和错误信息

### 界面说明

- **配置区**：设置 ES 连接参数、索引名称、批次大小、分隔符
- **文件选择区**：选择要导入的 CSV 文件
- **操作区**：开始导入、停止导入
- **进度区**：显示当前处理文件和导入进度
- **日志区**：实时显示导入日志（支持自动滚动）
- **统计区**：导入完成后显示详细统计信息

### 注意事项

1. **大文件处理**：对于超大 CSV 文件，工具会自动估算行数并进行分块
2. **错误容忍**：遇到格式错误的行会自动跳过，不影响整体导入
3. **超长记录**：单条记录序列化后超过 100MB 会被跳过
4. **重试机制**：网络错误会自动重试，最多 3 次
5. **编码问题**：优先 UTF-8，自动 fallback 到 GBK/GB18030

## 示例 CSV 格式

```csv
姓名,年龄,城市
张三,25,北京
李四,30,上海
王五,28,深圳
```

导入后的 Elasticsearch 文档：

```json
{
  "姓名": "张三",
  "年龄": "25",
  "城市": "北京"
}
```

## 性能优化建议

1. **批次大小**：根据网络状况和 ES 性能调整，通常 500-2000 之间
2. **Release 模式**：生产环境建议使用 `--release` 编译，性能提升显著
3. **网络带宽**：确保网络稳定，避免频繁重试
4. **ES 配置**：根据数据量调整 ES 的 `bulk` 相关参数

## 故障排除

### 连接失败
- 检查 ES 地址是否正确
- 确认 ES 服务是否运行
- 检查网络连接和防火墙设置
- 验证用户名密码是否正确

### 导入失败
- 查看日志区的错误信息
- 检查 CSV 文件格式是否正确
- 确认索引名称符合 ES 命名规范
- 检查 ES 磁盘空间是否充足

### 分隔符检测错误
- 尝试手动指定分隔符
- 检查 CSV 文件是否包含表头
- 确认文件编码是否正确
